# AP-Cosmetics — HTML/CSS/Bootstrap + Node/Express

## চালানোর নিয়ম

### 1) Backend
```
cd backend
npm install
npm start
```
চলবে http://localhost:5001 এ (Coke store এর সাথে পোর্ট না মিলার জন্য 5001 রাখা হয়েছে)।

### 2) Frontend
`frontend/index.html` ডাবল ক্লিক করে ব্রাউজারে খোলো। Backend আগে চালু থাকতে হবে।

## ফাইল কোথায়
- CRUD API: `backend/server.js`
- প্রোডাক্ট ডেটা: `backend/data/products.json`
- পেজ: `frontend/index.html`
- রং/ডিজাইন (pink/gold cosmetics থিম): `frontend/css/style.css`
- JS লজিক: `frontend/js/app.js`
