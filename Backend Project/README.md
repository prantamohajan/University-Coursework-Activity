# খাতা — পণ্য ব্যবস্থাপনা (Product Management)

সম্পূর্ণ CRUD (Create, Read, Update, Delete) প্রজেক্ট — ব্যাকএন্ড ও ফ্রন্টএন্ড আলাদা ফোল্ডারে।

## গঠন

```
project/
├── backend/
│   ├── server.js              → মূল সার্ভার
│   ├── package.json
│   ├── data/
│   │   ├── products.json      → পণ্যের ডেটা
│   │   ├── db.js              → পণ্য ফাইল পড়া/লেখার হেল্পার
│   │   ├── admins.json        → এডমিন অ্যাকাউন্ট (হ্যাশ করা পাসওয়ার্ড সহ)
│   │   └── adminDb.js         → এডমিন ফাইল পড়া/লেখার হেল্পার
│   ├── controllers/
│   │   ├── create.js          → CREATE — পণ্য
│   │   ├── read.js            → READ — পণ্য
│   │   ├── update.js          → UPDATE — পণ্য
│   │   ├── delete.js          → DELETE — পণ্য
│   │   └── admin/
│   │       ├── register.js    → CREATE — নতুন এডমিন
│   │       ├── login.js       → লগইন যাচাই
│   │       ├── list.js        → READ — এডমিন তালিকা
│   │       └── delete.js      → DELETE — এডমিন সরানো
│   └── routes/
│       ├── productRoutes.js
│       └── adminRoutes.js
└── frontend/
    ├── index.html             → ড্যাশবোর্ড (লগইন ছাড়া ঢোকা যায় না)
    ├── login.html             → এডমিন লগইন পেজ
    ├── css/
    │   ├── style.css
    │   └── login.css
    └── js/
        ├── api.js             → fetch() হেল্পার
        ├── authGuard.js       → লগইন চেক করে, না থাকলে login.html-এ পাঠায়
        ├── login.js           → লগইন ফর্মের লজিক
        ├── create.js / read.js / update.js / delete.js   → পণ্য CRUD
        ├── adminCreate.js / adminRead.js / adminDelete.js → এডমিন ম্যানেজমেন্ট
        └── app.js             → সব কিছু একসাথে চালু করে
```

## চালানোর নিয়ম

```bash
cd backend
npm install
npm start
```

এরপর ব্রাউজারে যান: **http://localhost:4000** — লগইন ছাড়া থাকলে সরাসরি লগইন পেজে নিয়ে যাবে।

**ডিফল্ট লগইন:** ইউজারনেম `admin`, পাসওয়ার্ড `admin123`

(সার্ভার ফ্রন্টএন্ড ফাইলগুলোও একসাথে সার্ভ করে, তাই আলাদা করে ফ্রন্টএন্ড চালানোর দরকার নেই।)

## API এন্ডপয়েন্ট — পণ্য

| মেথড   | পথ                  | কাজ                |
|--------|---------------------|--------------------|
| POST   | /api/products        | নতুন পণ্য যোগ করা   |
| GET    | /api/products        | সব পণ্যের তালিকা    |
| GET    | /api/products/:id     | একটি নির্দিষ্ট পণ্য  |
| PUT    | /api/products/:id     | পণ্য হালনাগাদ করা   |
| DELETE | /api/products/:id     | পণ্য মুছে ফেলা      |

## API এন্ডপয়েন্ট — এডমিন

| মেথড   | পথ                  | কাজ                                          |
|--------|---------------------|-----------------------------------------------|
| POST   | /api/admin/register  | নতুন এডমিন তৈরি (পাসওয়ার্ড হ্যাশ হয়ে জমা হয়)    |
| POST   | /api/admin/login     | ইউজারনেম/পাসওয়ার্ড যাচাই করে লগইন               |
| GET    | /api/admin           | সব এডমিনের তালিকা (পাসওয়ার্ড ছাড়া)             |
| DELETE | /api/admin/:id        | এডমিন সরিয়ে ফেলা                              |

### লগইন সিস্টেম কীভাবে কাজ করে
- পাসওয়ার্ড `bcryptjs` দিয়ে হ্যাশ করে `admins.json`-এ জমা থাকে, প্লেইন টেক্সটে না
- সফল লগইন হলে ব্রাউজারের localStorage-এ সেশন থাকে, তারপর ড্যাশবোর্ডে যায়
- ড্যাশবোর্ডের "এডমিন ম্যানেজমেন্ট" প্যানেল থেকে নতুন এডমিন যোগ ও পুরনো এডমিন সরানো যায়
- শেষ এডমিন অ্যাকাউন্টটি মোছা যাবে না, যাতে লক-আউট না হয়ে যাও
- **সতর্কতা:** এটা শেখার জন্য সহজ অথেন্টিকেশন (JWT/সেশন টোকেন নেই) — প্রোডাকশনে আরও শক্তিশালী ব্যবস্থা দরকার
